MIS Builder Analytic

This module allows you to create a MIS report using Analytic entries as data source

Usage

  1. Go to Accounting -> Reporting -> MIS Reporting -> MIS Reports.
  2. Create a new MIS Report
  3. On MIS Report form view enable comparison mode and create a new Period on Columns tab.
  4. In this form view select Actuals (alternative) option on the field Source and select MIS Account Analytic Line on the field Move lines source,
  5. Complete the rest of the report fields and click on Preview button.
  6. You will see the report based on Account Analytic Lines.
